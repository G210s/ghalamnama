Ghalamnama extension privacy policy

Applies to the Ghalamnama Multilingual Keyboard extension for Chrome and Firefox. Effective 27 September 2026.

In short: the extension does not collect, sell, share or transmit any data. It makes no network requests. Everything it remembers stays in your browser.

What the extension reads

The extension runs only on tabs where you activate it. On those tabs it reads:

  • which text field has focus, so the keyboard can insert characters there;
  • the keys you press on your physical keyboard, so they can be converted to the selected layout (for example Persian or Greek).

This happens entirely inside the page in your browser. What you type is never recorded, stored, logged or sent anywhere.

What the extension stores

Using your browser's built-in extension storage, on your device only:

  • your preferences: enabled languages, default language, typing mode, key highlighting, the reveal shortcut, and whether setup is complete;
  • where you dragged the floating keyboard button, and whether you hid it;
  • which open tabs you activated it on. This list is cleared when the browser closes.

None of this contains page content, page addresses or anything you typed. You can erase it at any time with Reset all settings on the extension's settings page, or by removing the extension.

What the extension does not do

  • No analytics, telemetry, tracking, advertising or crash reporting.
  • No accounts, cookies or remote servers.
  • No remotely loaded code: all code ships inside the extension package.
  • No sale or transfer of data to third parties, and no use of data for creditworthiness or lending.

Why it asks for access to websites

The keyboard has to work inside the text fields of whatever site you are on, and must come back after the page reloads on a tab you activated. That requires permission to run on websites. The extension uses this permission only on tabs you activate, and only to show the keyboard and insert characters.

Links out of the extension

The extension's menu links to this website, GitHub and an email address for feedback. These open only when you click them. They are covered by their own privacy policies, not this one.

Changes and contact

If this policy changes, the new version will be posted on this page with a new effective date. Questions: support@ghalamnama.online. The source code is public at github.com/G210s/ghalamnama.
