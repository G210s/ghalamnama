Activate it where you need it

  1. Open a regular webpageGhalamnama cannot run on protected Firefox pages.
  2. Select the Ghalamnama toolbar iconPin it from the extensions menu if you want faster access.
  3. Activate the current tabChoose “Activate on this tab,” or press Alt + Shift + G (Control + Shift + G on Mac), then focus a text box.
Quick switchPress Ctrl + Shift + Space to switch physical typing between Ghalamnama and your system keyboard.

Ready—with privacy by default

Choose how physical typing should start. Virtual keyboard buttons remain available in either mode.

Your typing stays private. Ghalamnama does not collect or transmit what you type, page addresses, or usage telemetry.
